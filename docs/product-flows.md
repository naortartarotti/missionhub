# Product flows

**Candidate owner (A):** Candidates → add/import (drafts) → record processing authorization → *Activate for matching* → Opportunities (Strong / Potential / Not eligible) → *Why this match* drawer → *Review match* → choose fields & documents, record job-specific authorization, confirm interest → Submit → Referral detail (timeline, messages) → confirm collaboration agreement when B accepts → follow progress → Commissions (projected → payable → paid after confirming payout receipt).

**Job owner (B):** Jobs → new (paste description → suggested requirements → review) → enable partner referrals & choose pre-referral visibility → job page shows anonymized match counts → Referrals › Received → review snapshot → Accept / Decline (reason) / Request info → Interviewing → Offer → Report hire (fee, start date) → Commissions: record invoice → record client payment → (after platform verification) record payout & platform remittance.

**Org admin:** Settings › Team (invite by one-time link, roles, suspend), Privacy requests, Audit log.

**Platform admin (/admin):** metrics, evidence verification queue, disputes, commission rule versions, org suspension.

Every screen has empty, loading, error and success states. Statuses always pair an icon with text.
